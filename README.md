## 🚀 Currently Building

### `SIRONA`

**SIRONA** is my biggest project so far — a personal AI assistant project built around the idea of making technology feel more natural, useful, and interactive.

Rather than being just another chatbot, SIRONA is an ongoing experiment in creating a more capable personal assistant that can interact with the user, understand requests, perform tasks, and become a more useful part of everyday digital workflows.

SIRONA is also the **parent project for a growing ecosystem of smaller projects and experiments**.
